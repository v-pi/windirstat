+Résumé du Projet : WinDirStat ➔ SpaceMonger 1.4 (SM14)
+
+Objectif : Transformer le rendu "Cushion Treemap" (3D) de WinDirStat en un look "Nested Flat" (emboîté et plat) identique à SpaceMonger 1.4.
+1. Configuration Environnement
+
+    IDE : Visual Studio 2022 (v143 outils de build).
+
+    SDK : Windows 11 SDK + Universal C Runtime (nécessaire pour new.h).
+
+    Note Debug : Ne pas lancer VS en mode Admin pour que le débugueur puisse s'attacher au processus.
+
+2. Architecture de la modification (TreeMap.cpp)
+
+Nous avons hacké la fonction CTreeMap::DrawTreeMap pour passer d'un rendu pixel par pixel à une logique de "boîtes".
+
+    Structure DrawState : Ajout de int depth pour suivre la profondeur dans la hiérarchie.
+
+    Cycle de Couleurs : Utilisation d'une palette fixe (Rouge, Orange, Jaune, Vert, Bleu, Violet) basée sur depth % 6.
+
+    Header & Frame : Pour chaque dossier, on dessine une barre de titre (Header) de 18px et on réduit l'espace des enfants (DeflateRect) pour créer un cadre coloré sur les côtés et le bas.
+
+3. Logique d'Agrégation (Le "Génie" de SM14)
+
+Pour éviter la pollution visuelle ("poussière" de petits fichiers) :
+
+    Seuil de zone : Si un objet fait moins de 400 pixels carrés à l'écran, il est agrégé (bloc uni).
+
+    Exception de Taille : Si un fichier/dossier dépasse SIGNIFICANT_SIZE (fixé à 5 Mo), il est toujours affiché, même si la zone écran est petite. Cela permet de voir les gros fichiers cachés dans WinSxS.
+
+    Hit-Test : La fonction FindItemByPoint a été modifiée pour s'arrêter au même niveau que le rendu (on ne peut pas cliquer sur ce qui est caché).
+
